# Week 6 - My Study Planner

A simple student study planner website using HTML, CSS, and JavaScript.

## Five interactions
1. **DOMContentLoaded**: Automatically displays good morning, afternoon, or evening.
2. **click**: Light/Dark Mode button changes the page theme.
3. **focus**: Clicking into the task box changes the helper text.
4. **submit**: Adding a task updates the visible list.
5. **change**: Checking a task marks it done and updates the completed-task count.

Open `index.html` in a web browser to use the website.
